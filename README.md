# 🛡️ Fake Reviews Detection using Machine Learning

A machine learning project developed during the **Data Hackathon** at the **5th National Data Science Summit 2026**, organized by Daffodil International University.

## 📌 Project Overview

Fake reviews and spam comments significantly impact the credibility of online platforms and influence customer purchasing decisions. This project focuses on detecting deceptive reviews by leveraging machine learning techniques and systematic data analysis.

The workflow includes data preprocessing, feature engineering, model comparison, and ensemble learning to develop a reliable solution for a real-world business problem.

---

## 🎯 Objectives

- Detect fake reviews and spam comments using machine learning.
- Perform comprehensive data preprocessing and feature engineering.
- Compare multiple classification algorithms.
- Evaluate models using standard performance metrics.
- Explore ensemble learning techniques for improved prediction.

---

## 📂 Datasets

This project utilizes publicly available datasets, including:

- Amazon Food Reviews
- Facebook Spam Comments

---

## ⚙️ Workflow

- Data Loading
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Train/Test Split
- Model Training
- Model Evaluation
- Ensemble Learning
- Performance Comparison
